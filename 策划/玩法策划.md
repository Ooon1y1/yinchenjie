### 2.3 三层连招架构（对齐苍翼混沌效应手感）

所有武器采用「**基础普攻链 + 分支派生 + 终结技**」三层结构：

1. **基础普攻链**：连续按 J 触发的自动连段，每段有独立伤害、硬直、攻击范围，数据见第 3 节各武器配表
2. **分支派生**：普攻任意一段后，按「K + 方向」触发不同派生技能（上挑、下砸、突刺、回马枪等），伤害与消耗见第 3 节
3. **终结技**：普攻链最后一段中按 K，释放高伤害终结招式
4. **空中连招**：默认锁定，词条「空武」或武器专属词条解锁（短刃「空中连斩」为其专属解锁途径）

### 2.4 取消机制（苍翼核心爽点）

攻击后摇阶段可通过特定操作强制取消，衔接下一个动作：

| 取消方式 | 触发条件 | 消耗 / 冷却 | 默认状态 |
| --- | --- | --- | --- |
| 闪避取消 | 攻击后摇前半段内按 Shift + 方向 | 15 点内息（⚠ D12：连招内取消半价，非连招轻功仍 30 点） | 默认开启，全武器通用 |
| 跳跃取消 | 攻击后摇前半段内按空格 | 无内息消耗，冷却 0.2 s | 默认锁定，词条「行云」解锁 |
| 派生取消 | 普攻命中瞬间起一段窗口内按 K | 无额外消耗，考验输入时机 | 默认开启（仅命中瞬间），词条「顺势」扩展至前摇后半段 |

> **派生取消窗口宽度（按武器）**：短刃 0.15 s（宽）＞ 长剑 / 长戈 0.10 s ＞ 重剑 0.05 s（窄）。
> **取消窗口定义**：闪避 / 跳跃取消窗口 = 后摇时长的前 50%；派生取消窗口 = 命中瞬间起，宽度按上表。
> **优先级**：`dash` 与 `perfect_parry` 可打断普攻链后摇（走取消机制）；前摇与攻击帧不可打断。

### 2.5 连击系统

| 项 | 规则 |
| --- | --- |
| 连击计数 | 每次攻击命中敌人 +1（多目标命中按次数累计） |
| 连击计时器 | 1.5 s，每次命中刷新 |
| 连击增伤 | 每 10 连击提升 3% 全局伤害，最高 30%（100 连击封顶），作为**独立乘区**与词条伤害加成叠乘 |
| 断档条件 | 计时器超时未命中、玩家被击中、切换武器 → 连击清零；词条「不断」改为受击仅减半 |
| 词条扩展 | 连击回血（血连）、连击回内息（息连）、增伤上限提升（连击精通），见第 4 节 |

### 2.6 保留机制（v1.1 定稿）

1. **格挡**：持续消耗 5 内息/秒，格挡成功减免 70% 伤害
2. **完美弹反**：触发后敌人僵直 1 s，玩家无敌 0.3 s，自动发射反击剑气（伤害 20）
3. **轻功闪避**：冲刺距离 180 px，全程无敌帧，消耗 30 内息，空中可使用，仅水平方向
4. **蓄力重击**：最长蓄力 0.6 s，满蓄伤害 35，消耗 20 内息

**破甲定义**：满蓄重击命中处于格挡状态的敌人时，击破其格挡并使其 1.5 s 内无法再次格挡，造成全额伤害。此为 BOSS「格挡」招式的首要破解手段（见 5.4）。🆕 派生技在持有「破甲」词条后同样具备此效果；重剑「崩山劈」破甲禁格挡时间翻倍为 3 s（D11）。

### 2.8 玩家状态机（v2.0 扩展）

状态列表：`idle` / `walk` / `jump` / `fall` / 🆕`combo_1` ~ `combo_n`（各武器普攻段）/ 🆕`derive`（派生技）/ 🆕`finisher`（终结技）/ `heavy_attack` / `block` / `perfect_parry` / `dash` / 🆕`weapon_switch` / `hurt` / `death`

- 🆕 连招状态采用「当前段 + 输入缓存」机制：输入缓存 0.2 s（提前按下一次 J/K，到可衔接帧自动触发）；普攻衔接窗口沿用 0.3 s（可被词条延长）
- 攻击、受击状态有硬直，不可打断；闪避、弹反有优先级，可按取消机制打断后摇；前摇与攻击帧不可打断

### 2.9 输入缓存与衔接窗口的区分

| 概念 | 数值 | 作用 |
| --- | --- | --- |
| 输入缓存 | 0.2 s | 提前输入的下一次普攻 / 派生在可衔接帧自动触发 |
| 衔接窗口 | 0.3 s（默认） | 命中后允许继续连段的持续时间，超时回 `idle` 并重置段数 |
