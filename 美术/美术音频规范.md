## 1. 风格与基础参数

| 项 | 数值 / 规范 |
| --- | --- |
| 美术风格 | 青绿水墨像素风，低饱和「青 / 碧 / 灰」配色，尘雾秘境氛围 |
| 全局 PPU | 100（100 像素 = 1 游戏单位） |
| 瓦片尺寸 | 16×16 px |
| 角色精灵尺寸 | 32×32 px |
| 动画帧率 | 10 FPS |
| 色彩空间 | sRGB |
| 文件格式 | 带透明通道用 PNG，大型背景可用 WebP |
| 命名规则 | 蛇形命名（snake_case），禁止「中文 / 空格 / 特殊字符」 |
| 设计分辨率 | 640×360（16:9），整数倍缩放至全屏，纹理过滤 nearest |

## 3. 必须产出资源清单

1. 主角精灵表：`idle` / `walk` / `jump` / `fall` / `light_attack_1` ~ `light_attack_3` / `heavy_charge` / `heavy_release` / `block` / `parry` / `dash` / `hurt` / `death`；🆕 连招升级新增：`derive_up`（上挑）/ `derive_qi`（剑气斩）/ `combo_4`（回身斩）/ `finisher`（青云斩）/ `air_attack_1` ~ `air_attack_3`（空中普攻）
2. 🆕 武器姿态精灵表（P1）：四武器各需 `idle`（持武器）+ 全普攻段 + 派生 + 终结技动作
3. 敌人精灵表：每种敌人对应 `idle` / `walk` / `attack` / `hurt` / `death`；🆕 新增 `launched`（浮空，2 帧）/ `stunned`（眩晕，2 帧）
4. 瓦片集：云涧松径地面、平台、墙体、装饰（古松、石碑、云雾）
5. UI 素材：血条、内息条、按钮（normal / hover / pressed 三态）、弹窗面板（九宫格）；🆕 连击数字字体图（0-9 大号像素字）、眩晕图标
6. 特效：剑气、弹反闪光、轻功残影、击中火花；🆕 上挑挑空轨迹、震地冲击波、终结技斩光大特效、连击里程碑脉冲

## 4. 动画帧数表（10 FPS，每动作一张 PNG，帧横排）

| 动作 | 帧数 | 循环 |
| --- | --- | --- |
| idle | 4 | 是 |
| walk | 6 | 是 |
| jump / fall | 各 1 | 否 |
| light_attack_1 / 2 / 3 | 各 3 | 否 |
| heavy_charge | 2 | 是（蓄力 0.6 s 内循环） |
| heavy_release | 3 | 否 |
| block / parry | 1 / 2 | 否 |
| dash | 4 | 否 |
| hurt | 2 | 否 |
| death | 6 | 否（定格末帧） |
| 🆕 derive_up（上挑） | 3 | 否 |
| 🆕 derive_qi（剑气斩） | 3 | 否 |
| 🆕 combo_4（回身斩） | 3 | 否 |
| 🆕 finisher（青云斩） | 4 | 否 |
| 🆕 air_attack_1 / 2 / 3 | 各 3 | 否 |

敌人通用：`idle` 4 帧（循环）、`walk` 6 帧（循环）、`attack` 4 帧、`hurt` 2 帧、`death` 6 帧；🆕`launched` 2 帧、`stunned` 2 帧。
